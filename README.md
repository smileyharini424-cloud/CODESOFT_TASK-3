# ATM Interface

## CODSOFT Java Development Internship - Task 3

### Project Description

The ATM Interface is a Java console-based application that simulates basic ATM operations. It allows users to check their account balance, deposit money, and withdraw money.

### Features

- Check account balance
- Deposit money
- Withdraw money
- Validate withdrawal amount
- Check for insufficient balance
- Exit the ATM safely

### Technologies Used

- Java
- Java 21
- VS Code

### Concepts Practiced

- Classes and Objects
- Encapsulation
- Methods
- Scanner for user input
- Conditional statements
- Switch statement
- Do-while loop
- Input validation

### How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program:

```bash
javac ATMInterface.java
Run the program:
java ATMInterface
